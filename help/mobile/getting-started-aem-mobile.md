# Adobe Experience Manager Mobileの導入方法{#getting-started-with-aem-mobile}

{{ue-over-mobile}}

>[!CAUTION]
>
>既存のAdobe Experience Manager（AEM）モバイルアプリのお客様がAEM 6.2または6.3からAEM 6.5に移行する場合、引き続きPackage ShareからパッケージをダウンロードしてAEM Mobile Appsを使用できます。 ただし、AEM 6.5の新しいインストールでは、AEM Mobile アプリ機能はサポートされていません。

AEM Mobileは、AEM Assets、Sites、Screens、Workflow、User Manager、Commerce、Formsも使用するAdobe Experience Managerのマルチチャネルデジタルプラットフォームの一部です。 AEM Mobileの優れた柔軟性により、企業は様々なコンテンツソースを柔軟に活用できます。

AEM Mobileでは、アプリを作成するための複数の方法が用意されています。 アプリを作成するには、次の3つの方法があります。

* **[AEMでのオンデマンドサービスの使用](/help/mobile/getting-started-aem-mobile-on-demand.md)**
* **[AEMを使用しないオンデマンドサービスの使用](https://helpx.adobe.com/digital-publishing-solution/help/aem-mobile-end-of-life-faq.html)**
* **[Adobe PhoneGap EnterpriseとAEMの併用](/help/mobile/getting-started-aem-mobile-phonegap.md)**

>[!NOTE]
>
>Adobe Experience Managerを初めて使用する場合は、[AEMの概要](/help/sites-deploying/deploy.md)を順を追って説明します。
