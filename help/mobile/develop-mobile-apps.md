# モバイルアプリ{#mobile-apps}

{{ue-over-mobile}}

Adobe Experience Manager（AEM）モバイル版は、AEM Assets、Sites、Screens、Workflow、User Manager、Commerce、Formsも使用しているAEMのマルチチャネルデジタルプラットフォームの一部です。 AEM Mobileの優れた柔軟性により、企業は様々なコンテンツソースを柔軟に活用できます。

AEM Mobileでは、アプリを作成するための複数の方法が用意されています。 アプリの作成に使用できるさまざまな方法は次のとおりです。

* [AEM Mobile On-demand Servicesの導入方法](/help/mobile/aem-mobile-on-demand.md)
* [AEMを使用したAdobe PhoneGap Enterpriseの概要](/help/mobile/developing-in-phonegap.md)

>[!NOTE]
>
>Adobe Experience Managerを初めて使用する場合は、[AEMの概要](/help/sites-deploying/deploy.md)を順を追って説明します。
